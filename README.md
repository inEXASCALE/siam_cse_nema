# SIAM CSE27 double minisymposium

Static, build-free website for the double minisymposium **Number Formats, Emulation Schemes, and Mixed Precision Numerical Algorithms**.

## Publish with GitHub Pages

Push `index.html` and `styles.css` to a GitHub repository. In **Settings → Pages**, choose **Deploy from a branch**, select the branch (usually `main`) and the **`/ (root)`** folder. The site needs no build step.

## Content sources

- Talk titles: `main.tex` supplied by the organizers.
- Session order, times, and current affiliations: the [official Part I](https://meetings.siam.org/sess/dsp_programsess.cfm?SESSIONCODE=90903) and [Part II](https://meetings.siam.org/sess/dsp_programsess.cfm?SESSIONCODE=90904) program pages.
- Presenter logistics: SIAM CSE27 registration and general information pages, plus the supplied participant notice.

The official program lists Enrique S. Quintana-Ortí at Universidad Politécnica de Valencia, while the supplied LaTeX file says Universitat Jaume I. The website follows the official program; confirm with the speaker before treating this as a final correction.
